# Research Collaborations Within and Across Disciplines in NIH-Funded Atlas Programs

This site provides the supporting data, analysis code, tables, figures, and co-authorship network visualizations for the comparative analysis of HTAN, HuBMAP, and SenNet.

The project examines collaboration by consortium component, researcher role, and publication impact across the three NIH Atlas programs.
